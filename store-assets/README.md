# Store artwork

Editable SVG sources live in `source/`. The checked-in PNGs under
`fastlane/metadata/android/en-US/images/` are the Play Console deliverables.

Current dimensions:

- Play icon: 512 × 512 PNG;
- feature graphic: 1024 × 500 PNG.

The feature graphic contains no text so it can be reused for every locale.
Phone screenshots must be captured again from the exact signed release
candidate whenever setup, disclosure, tile, or branding changes.
